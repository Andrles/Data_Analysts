# Анализ факторов конверсии в интернет-магазине

[![Открыть в Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Andrles/Data_Analysts/blob/main/user_activity_analysis.ipynb)

## Цель проекта

Выявить поведенческие и сезонные факторы, связанные с покупкой в интернет-магазине, и подготовить рекомендации для повышения конверсии.

## Данные

Использован открытый датасет [Online Shoppers Purchasing Intention Dataset](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset) от UCI Machine Learning Repository. Он содержит **12 330** сессий посетителей интернет-магазина и признак совершения покупки.

Данные автоматически скачиваются при первом запуске и не хранятся в репозитории.

## Инструменты

Python, pandas, matplotlib, seaborn, Jupyter Notebook.

## Ключевые результаты

| Метрика | Значение |
| --- | ---: |
| Пользовательских сессий | 12 330 |
| Общая конверсия в покупку | 15.5% |
| Конверсия новых посетителей | 24.9% |
| Конверсия возвращающихся посетителей | 13.9% |
| Конверсия в ноябре | 25.4% |

### Наблюдения

- Новые посетители конвертируются почти в **1,8 раза** лучше возвращающихся.
- Ноябрь — самый сильный месяц по конверсии; пик достигает 25,4%.
- В выходные конверсия составляет 17,4%, против 14,9% в будни.
- У сессий с покупкой среднее значение `PageValues` заметно выше. Это связь, а не доказательство причинности.

## Рекомендации для бизнеса

- Увеличить маркетинговую активность перед ноябрьским пиком спроса.
- Проверить путь возвращающихся посетителей: персональные предложения, напоминания о товарах в корзине и программы лояльности.
- Проанализировать страницы с высоким `PageValues` и использовать их элементы в посадочных страницах.
- Отдельно тестировать предложения в выходные, когда конверсия выше.
